Økonometri I, KU
Noter og slides fra min holdundervisning i Økonometri I på KU (forår 2026)

- Kurset dækker estimationsmetoderne OLS, IV, FD, FE og RE samt robuste standardfejl.

- Metoderne anvendes på tværsnitsdata (hovedfokus), tidsserier og paneldata.

- Derudover udvikler kurset færdigheder inden for analyse, videnskabelig formidling og STATA.
